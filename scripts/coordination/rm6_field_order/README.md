# RM-6 field-order grammar prototype

`grammar.py` emits two GBNF arms with identical value rules and mandatory top-level fields in opposite experiment order. Both permit empty or populated evidence and use the full ReviewDecision schema's nested `advisory.feedback`. The common value language is intentionally narrower than the complete schema (for example, evidence uses `kind` and `ref` only). This offline prototype is not integrated into a runner, has not been checked against the target decoder, and does not establish a publishable experiment. It does not pick a leading model, define a decision rule, or provide paired statistical analysis.

Run `/mnt/raid0/llm/epyc-orchestrator/.venv/bin/python -m unittest discover -s scripts/coordination/rm6_field_order -p 'test_*.py'` for the offline checks. The full-schema test uses the checked-out orchestrator schema and skips if the schema or `jsonschema` is unavailable; pin and revalidate that schema at integration. Before any study, verify grammar parsing and actual constrained outputs on the exact pinned decoder without treating these unit checks as decoder proof. Pin the grammar, model, corpus, and protocol as required by RM-6.
