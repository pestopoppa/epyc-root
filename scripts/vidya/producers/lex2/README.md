# CS-8.LEX2 prospective capture

This directory contains a prospective dev runner template, native capture helpers, strict Speech adapter integration, and model-free controls. A future producer must place the runner and helpers into a dedicated packet with its own pinned plan, input manifests, source catalog, executable, and predeclared scorer. The template is not a grant, a qualified launcher, or a heldout READY packet. The existing 2026-10-31 1,500 raw outputs predate this capture and cannot be projected as if this writer had run.

The producer records native result status separately from an instrumentation-unknown disposition, preserves exposed unknowns without redraw, and emits a terminal inconclusive-exhausted marker once all declared cells are addressed. `complete_predicate.py` reports exhaustion of the declared work only; it is not a scientific pass predicate. Normal and cutoff qualification through the canonical engine remains necessary before any future grant. Heldout adoption requires a separately built and qualified runner with the frozen actual dev selection and the declared overlap rules.

`emit_lex2_observations.py` replays the hash-pinned dev scorer against the original native run directory before asking the existing Speech writer to emit observations. The adapter projects through the existing measurement source and shared grading ladder. The source hook and synthetic planning-context canary do not confer a historical measurement warrant or prove that a real future runner is qualified.

Run `python3 tests/test_adapter.py` and `python3 tests/test_native_launcher.py` with the repository root on the host, subject to the site CPU-admission rules. Their inputs and engine processes are synthetic; no model is loaded.
