# R18 prospective input bundle

The comparator and CUID replay files are byte-identical copies of the retained r4 evidence packet. The two Perl modules retain their r4 pinned contents; the new dependency manifest replaces only their ephemeral absolute paths with `@bundle/` paths. Runtime resolves them inside this directory and verifies every digest. `production-recipe.json` contains only the CPU/GPU `configure_definitions` extracted from the r4 full recipe, whose SHA-256 is `1fdfb98c043333ff3139c190b252ae3066ef4bd5ee612620c53bbe4efaaf40e7`; the driver pins the extracted file's SHA-256 before and after the build. `replay_evidence.py` is a successor variant using the frozen versioned kernel store and the local comparator, with otherwise unchanged r4 checks. Neither the r4 result nor its scratch is changed.
