# TOC-CMP-3: compaction artifact contract

`orchestrator.patch` applies to epyc-orchestrator commit `12afe2858f9dbd4691447926d6cf1864de64348c` (the `origin/main` resolved when prepared). Patch SHA-256: `1b679a01e14e631ea58e6bcfe94f15e59195245b2309aab072d0bbfaaffaa0c3`. Verify the base and `git apply --check` before applying. No live service or kernel changes are included.

The default-off `context_compaction_contract` feature depends on the existing `context_arm_ab` experiment and requires explicitly supplied contract data. Use `set_contract(state, ExecutionBrief(...), PinnedGovernance(text=...))` before rendering or a boundary. The brief requires six nonempty strings: `verbatim_task`, `current_intent`, `plan`, `completion_requirements`, `artifacts`, and `pointers`. Inputs containing control tokens that would be neutralised are rejected. The contract is prepended outside history folding and checked against the exact caller-supplied framed text on every rendered view, including after a boundary. Missing or altered contract text raises an error. This is literal preservation, not proof that a model understands or semantically entails the text; callers remain responsible for supplying complete, accurate inputs and ensuring later prompt assembly does not alter the view.

`verbatim_manifest` is an additional opt-in arm. It lists each omitted turn's code, output, and error character span, a UTF-8 SHA-256 digest, and a `peek` pointer into the registered session log. Retained tail turns are excluded. This reports exact content absent from that view; it does not infer semantic loss. Existing arms and the legacy default-off path remain available.

Offline validation: the focused test suite exercises all arms, default-off equality, missing and altered contract rejection, unsafe control-token rejection, and Unicode span retrieval. No inference or live model test was run; the empirical CMP-3 comparison remains separate work. `make gates` could not complete because `shellcheck` is not installed in the environment.
