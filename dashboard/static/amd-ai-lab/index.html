One user or the whole server?

Per-request decode measures an individual response. Wall-clock aggregate measures all completed tokens over elapsed time. Qualification curves separately report the sum of request decode rates. Higher concurrency can raise one while lowering the other.

Same kernel. Different evidence.

The KV studies use the frozen v10 binary, but one sample per cell is exploratory. A measured difference is not a proven speedup. Recipe and sample counts stay beside every chart.
