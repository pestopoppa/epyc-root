4. `:8000` currently ignores unknown `x_*` keys (pydantic `extra="ignore"`), so P0.4 must follow P0.2.
5. FastMCP 1.27.0 silently drops an undeclared `session_id`. Orchestrator/memory MCP tools must declare it.
6. Title generation now fires `chat.params` (HS-1g caveat obsolete). It stays disabled.
7. New keyed side call: TUI project-copy naming, which uses a synthetic session id.
