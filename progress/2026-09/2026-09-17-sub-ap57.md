## AP-63(a) — landed (orchestrator `0286c170`)

- **`run_manifest` on journal rows.** `JournalEntry` has a new `run_manifest` field. The AP-1510
  manifest was previously bound only to the in-flight WAL marker, which is cleared after the row is
  written. It is now copied onto the journal row for:
  - main-loop rows;
  - dispatcher-skip rows;
  - the AUTOPILOT_KILLED placeholder.

  An undispatched trial, a marker for another trial, or a legacy marker gets `{}`. No manifest is
  built at write time, and nothing is back-filled. The claim tuple carries the digest.
- **`lineage` (explicit stored parent).** The rule is `latest_committed_baseline_promotion_same_species`:
  the parent is the newest same-species trial with a `baseline_promotion` ledger event. A row never
  qualifies if it is:
  - pending;
  - bug-corrupted, including through supersession;
  - another species;
  - later than the trial.

  With no accepted parent, the id is `None`. The legacy heuristic is recorded alongside and still
  feeds `parent_trial`, so behaviour is unchanged.
- **Belief kernel.** The root `scripts/vidya/adapters/autopilot_journal.py` carries the digest,
  ungraded (root commit on this branch). The README row was updated. An end-to-end check from the
  real writer to the adapter passed: digest carried, attestation still verifies.
