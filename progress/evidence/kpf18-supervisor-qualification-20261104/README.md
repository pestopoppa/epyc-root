# KPF-18 native-control output supervision qualification

Three model-free tests exercise the pinned successor supervisor and guard snapshots in this directory. Run with `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s progress/evidence/kpf18-supervisor-qualification-20261104 -p 'test_*.py' -v`.

The periodic supervisor test injects output-budget failure on its second loop sample and checks rc 75, a PARTIAL receipt with unknown overshoot, and calls to stop and drain the owned child. The guard test exercises the real output-reserve logic against a sparse file grown to the 64 GiB logical cap. A separate real-process test verifies that a captured child and its adopted separate-session descendant, both ignoring SIGTERM, are killed and reaped. All three passed on 2026-11-04. The periodic supervisor test mocks process control; GPU admission and free-disk readings are also mocked. The real-process test covers a synthetic tree, not the GPU workload or uninterruptible processes. These tests establish neither a hard quota, bounded overshoot, end-to-end coverage, GPU admission nor native-control readiness. Source snapshots are pinned by hashes in the tests; they do not qualify the successor's separately missing or changed historical source inputs.
