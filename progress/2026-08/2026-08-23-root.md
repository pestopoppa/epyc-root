`sudo -n mkdir -p /mnt/bigdisk && sudo -n mount /dev/sdb1 /mnt/bigdisk`, planned writes to

## Restart requirement

opencode loads config+plugins at start — the OPERATOR MUST RESTART opencode for the plugin and
permission rules to load (running sessions have no guard until then). The Claude hook loads at
next session start. Residual gaps, stated: daemons/cron/scripts that shell out internally are
invisible to a PreToolUse guard (OS-level layer is the enforcement for those); `bash -c '...'`
inner commands are quoted data and not scanned; in the Claude surface an agent with shell access
to the session env could export the env-ack (the ratified D9 model) — the git-tracked allowlist
is the robust form. Working in the SHARED clone per the dispatch (explicit /workspace paths);
commits use strict pathspecs, never `git add -A`.
