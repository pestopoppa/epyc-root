### Static audit outcome

Our REPL scaffold is **cache-hostile but NOT SkyRL's literal re-append shape** (contradiction note at
handoff L119 resolved in the same direction as the 2026-07-25 read):

- `RootLMPrompt.to_string()` order: system → tools → rules → **state → context → reference_code →
  task → instruction** (`src/prompt_builders/types.py`). Per-turn mutators: `state` ("Turn N", rebuilt
  per turn), `context` (last output/error spillover), `reference_code` (corpus, turn-1-only,
  `graph/helpers.py:672`). Successive turns share only system+tools+rules; the fixed `## Task` sits
  past the divergence point → every turn is a full-prompt cache miss on the fixed part too.
- Frontdoor REPL bypasses all cache machinery by design: `ORCHESTRATOR_PREFIX_CACHE_BYPASS_FRONTDOOR_REPL`
  default "1" (role frontdoor + `"\n```\n"` in stop_sequences predicate) AND content-addressable cache
  skipped when `stop_sequences` set. Payload already sends `cache_prompt: true` + `id_slot`.

### Two instrumentation defects fixed (measurement was lying)

1. `LlamaServerBackend.get_slots()` read `n_past`/`n_cache` — gone in llama.cpp v9, always 0. Now
   reads `n_prompt_tokens` / `n_prompt_tokens_cache` (verified in `server-context.cpp
   server_slot::to_json`).
2. Cache-stats collector read response-level `tokens_cached` — that field is the TOTAL slot KV
   occupancy (`slot.prompt.n_tokens()`, `server-task.cpp:386`), non-zero for nearly every non-empty
   prompt → `cache_hits` inflated on almost every request. Now reads `timings.cache_n`
   (= `n_prompt_tokens_cache`, `server-context.cpp:511`) — the true KV-reuse count.

### Fix landed (flag-gated, default OFF)

New feature `ORCHESTRATOR_PREFIX_STABLE_ORDER` (+ `prefix_stable_order` on the Features dataclass,
FeatureSpec registered): `RootLMPrompt.to_string(prefix_stable=True)` renders the fixed sections
(task, instruction) BEFORE the per-turn-mutating sections (state, context, reference_code), wired
through `build_root_lm_prompt` so the fixed query joins the shared prefix. Default OFF pending live
A/B validation.

A/B harness: `scripts/benchmark/bench_repl_prefix_stability.py` — drives the real per-turn
`build_root_lm_prompt` sequence through llama-server `/completion` (`cache_prompt: true`, pinned
`id_slot: 0`, REPL stop sequence), sampling the true hit count per turn (`timings.cache_n`) for both
orders; `--order both|legacy|stable`, JSON output. Verified end-to-end (flag toggle, prompt build,
HTTP path) minus the live server.
