### Task 2 — resume ODL-011 code work

First real intrinsic run over the ODL-013 real prediction dirs exposed a real
defect: `DefaultChunker._recursive_split` used `re.split()` (dropping
separators) and `_merge_small_chunks` concatenated the fragments, so chunks
were no longer exact substrings of the source document — and
`find_chunks_start_and_end` (exact-match locator behind BI/ICC/DCC) raised
`ValueError: Chunk not found in text.` on real docs.

Fix (research repo, landed via shared-tree sweep `cd329746` alongside the
autokernel session's commit):

| Change | Detail |
|---|---|
| `_recursive_split` | now `_split_keep_separator()`: splits at separator positions keeping the separator attached to the following piece, so every piece is a contiguous slice of `text` (concatenating pieces reproduces the source exactly) |
| `split_text` | strips leading/trailing whitespace-only chunks after merge (interior ones were already merged); cannot break the substring invariant |
| `score_prediction_dir` | defensive per-document guard: a pathological doc is skipped with the error recorded in `detail`, never aborts the 200-file run |
| tests | +4 regression tests (every-chunk-is-substring, contiguity, find-on-chunker-output-never-raises, pathological-doc-skipped) — 30 intrinsic / 56 total OK |
