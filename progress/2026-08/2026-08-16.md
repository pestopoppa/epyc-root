## Defects the work surfaced (all fixed unless noted)

1. **The 2026-08-14 failure reproduced live.** Minutes after the ghost sweep, the daemon
   assigned four freshly-reset rows to mainA–D, dead for 58 hours. The fleet-wide gate could
   not catch it — a partially-dead fleet burns rows one dead agent at a time — so liveness
   is now a property of the RECIPIENT, checked where the recipient is chosen (P0-2b).
2. **`required_writer()` compared resolved paths**, so every symlinked bus file read as
   "outside the bus root" once the runtime moved. Containment is now logical (`normpath`):
   traversal still rejected, symlinks followed.
3. **The daemon wrote `priority: null`** on rows whose source had none — an optional string
   in its own schema, 65 invalid rows across 08-13/14, unseen because nothing ever ran
   `validate`.
4. **`check_commit_hygiene.py` read FETCH_HEAD only from the git common dir.** Git writes it
   per-worktree; the hook therefore reported a stale fetch to exactly the worktrees that had
   just fetched, blocking every pool-worker commit. **Found by the first pool worker**, which
   reported the denial instead of bypassing the hook.
5. **A heartbeat write race.** Three concurrent workers share one identity and collided on a
   fixed `.tmp` name; the temp name is now per-process.
6. **The permission profile shipped empty.** Configured and populated are different things.
7. **`for x in $VAR` ran once** (fish word-splitting) and silently moved nothing — caught by
   verifying rather than by trusting the exit code.
