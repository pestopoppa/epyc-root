## Findings

1. **S2 harness-corpus drift, fixed.** The MHS-3 harness corpus is the checkout's `src/**/*.py`.
   - Moving the suite alias table into `src/` raised `debugbench` to 4 harness files. That reached
     `_SUITE_HARNESS_VOCAB_FILES` and silenced its suite special-casing refusal, which is 3 of the
     736 golden verdicts.
   - Fix: the guard module's own source is excluded from the corpus. S1 had already put its tables
     there unnoticed; the exclusion also restores the pre-S1 corpus definition.
2. **Vacuous tests, fixed.** Before the S2 retarget, 4 leakage tests failed and 2 passed vacuously:
   they patched `prompt_forge` globals that no longer steered anything. A structural test now
   refuses any monkeypatch of a moved global on `prompt_forge`.
3. **Shared-clone `.pth`.** The orchestrator venv carries a `.pth` that puts the shared clone
   `/mnt/raid0/llm/epyc-orchestrator` on `sys.path`.
   - A script run from a worktree, without inserting its own root, imports the shared clone's
     `src`. That clone is at `8b630d27`, which has no `mutation_guards`, so
     `prompt_interference_calibration.py` failed from worktrees after S1. S5 fixed it; its output
     is byte-identical.
   - The live AutoPilot runs from the shared clone, so it picks up S1–S5 only once that clone is
     updated. No process was restarted here.
4. **Driver item-7 hole, fixed** (`c85b85ef`). `outcome_keys_in` scans keys, so a trace EVENT
   named `passed` or `score` went through the driver. The HIL-6h builder reported it.
5. **`gate_replay_reports.py` does not exercise `SafetyGate.check`.** It replays the sequential
   e-process. The plan named it as S4's replay; a purpose-built `check()` replay was used instead.
6. **Defects reported by the HIL-6i design work** (pilot doc §14; other owners; not changed here,
   because each changes live serving or research behaviour):
   - `build_architect_investigate_prompt` truncates the question at 2,000 characters, which cuts
     most `hotpotqa` and all `longbench` prompts;
   - a stale docstring in the research `tulving_trace_retriever.py`;
   - a run precondition: AutoPilot's PromptForge must exclude the pilot target while a pilot runs.
