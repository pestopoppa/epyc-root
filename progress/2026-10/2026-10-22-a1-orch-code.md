- **Session compaction is not a prefix-cache invalidation.**
  - `TaskState.context` is never rendered into a prompt (UFH14-B1), so compaction is deliberately not a `note_history_rewrite` producer.
  - The real history rewrites are the session-log block refresh/consolidation and escalation compression.
- **Error-turn tool calls go to the trajectory only.**
  - The session-log record's `tools:[...]` renders into the session-summary prompt block.
  - Adding the calls there would change prompt bytes, so the error-path calls reach the trajectory artifact only.
