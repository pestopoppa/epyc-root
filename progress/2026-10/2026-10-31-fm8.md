## Frontmatter field check (docs, code.claude.com/docs/en/sub-agents.md)

`name`, `description`, `tools` (comma string or list), `model`, `effort`, `maxTurns`, `omitClaudeMd` (needs Claude Code v2.1.271+), camelCase exact; unknown keys are silently ignored. Documented hook `tool_name` is `Agent` (`Task` is a legacy alias in settings, so the matcher keeps both). `agent_id`/`agent_type` are present inside subagents. Not documented: `fork` as a `subagent_type` value and a per-call `model` being ignored on a fork; the fork checks are therefore verified only on fixtures, not against a live payload.
