# EV-SKILL-NULL-REPLAY

This is an offline diagnostic transcription of the retained SkillsBench audit, not an EPYC promotion result. It uses `/mnt/raid0/llm/tmp/intake-nov26/audit.tree` at upstream revision `eef0fae38200676cee61ae345a057793bb668b78`; the JSON records SHA-256 hashes of each table used. The source and methodology are also described in `research/deep-dives/intake-nov26-kernels/audit.md` and `2611.33943.md`. No model, server or benchmark was run.

The 1,421 configuration–task pairs and 474 one-arm cells come from S02; the missing count is cells, not trials. Retained paired arms are condition labels, not proven seed-matched trials. The JSON carries IDs, means, timeouts and an exclusion for each paired cell. S05 supplies *declared* task skill names and two verifier warning flags; neither proves the effective per-run inventory or describes full scorer requirements. Raw trajectories, review exports and task verifier sources were not in this retained audit snapshot. Consequently every cell is excluded from promotion, and absent manifests and requirements are unresolved rather than assumed empty.

For split 0, join the frozen decision records by cell ID, check that both decision and held-out ID sets are disjoint and exhaust each arm, and retain decisions and held-out rewards. The 219 ineligible cells have fewer than two retained trials in an arm. The stored 60-split forest summaries and 2,000-split cutoff summary use repeated draws from the same trials; task-bootstrap intervals do not include model refitting uncertainty. There is no established unseen-task-family holdout. The 60 within-cell permutations refit policies after shuffling and report apparent gain against always loading on all 1,421 cells. Their replay and null populations differ from the 1,202-cell holdout; exchangeability is assumed and cell-level permutation assignments are not retained. The apparent gains (2.92, 2.95, 2.12 pp) are below their respective shuffle means (4.41, 6.54, 5.72 pp); the forest held-out intervals include zero. These comparisons do not authorize gating or prove equivalence. The upstream fixed cutoff also has a separately retained 2,000-split estimate; it differs from its 60-split estimate because of the draw count.
