# V9-8 native lifecycle successor

This packet preserves the fixed 20-request v10/v10 schedule and the original
model, executable, library and K35 pins. The runner preflight still checks the
canonical contention matrix under its live claim. The row precondition also
runs the standard validator before the engine enters its claim path. The row
stays unpublished until a genuine refresh for the production lineup passes
that validation.

The job preserves the resident refusal if no fresh replay completed. It
preserves a failed fresh replay's reason after successful resident capture.
A complete fresh fallback still goes through the unchanged strict sealer and
adapter.
