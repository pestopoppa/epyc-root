Prospective source preparation
==============================

Decode each JSON original-bytes envelope using bytes_b64 and verify sha256 to restore the original file before replay. Non-JSON source files are original bytes. receipt.json maps original names to archives and hashes. No model weights or runtime libraries are copied here. Original pregrant receipts bind those assets.

This archive prepares prospective metadata or a separately scoped CPU loader diagnostic. It does not establish native full capture, complete seven-profile parity, strict bank admission or promotion authority. New metadata checks are proposed policy for fresh production capture; they cannot amend an original run's warrant. The CPU diagnostic cannot stand in for architect-general HIP coverage.
