## Model (P3.4)

- **Tokens:** `c0..c95`. SMT siblings follow their core. `gpu` is the MI210 plus host threads 184-191. Counters: `ram_gib`, `disk_gib`.
- **Smoke lane:** fixed cores c20-23 (+116-119). It is never granted to rows and is carved out of every expansion: `q0`→20 cores, `0-95`→92.
- **Spec:** the 12 fields (+ `quiet_reason`, `measured_ack`, `supersedes`). A grant = the declaration stamped with a window of `1.5 × max(estimate_s, min_window_s)`.
- **Tick:**
  1. `reconcile()`: measured busy per core, KFD, idle release after 2 samples (only once a grant has shown a busy core; quiet grants never release), overrun alert at 1.5× estimate, smoke deadline kill.
  2. `admit()`: strict priority by (rank, published_at, id).
  3. `file()`.
- **8 tunables:** `SMOKE_CORES`, `IDLE_SAMPLES=2`, `IDLE_PCT=2.0`, `SMOKE_DEADLINE_S=1200`, `OVERRUN_FACTOR=1.5`, `QUIET_MAX_RANK=10`, `FILE_OWNERLESS_S=1200`, `CLAIM_TTL_S=7200`.
- **No inference from job text, argv, OMP or regex.**

## Decisions made in the build

1. **Legacy → `gpu`.** A row needs the gpu if `regions` contains `mi210*` or `shape` is gpu/gpu-q3.
   - **exclusive** for `gpu-q3`, `quiet-host` or `admission_class` `block-timing-*` ("timing exclusive").
   - **shared** for correctness, diagnostic or block-correctness ("correctness shares").
   - **No declared class → exclusive** (conservative). Most live GPU rows carry no class, so owners should declare one at republish.
   - `184-191` without gpu → unmappable.
2. **Hold.** Only the first non-fitting row holds, and it holds tokens only (not RAM or disk). Its ETA is the end of the grants that free its soonest option. A worse-ranked row may take held tokens only if `now + window ≤ ETA`. Better-ranked rows are admitted before the hold exists.
3. **Over-declaration is refused, never shrunk.** A small job declares `any-N-of-qX`. A successor whose predecessor measured `busy_p95 < 0.25` of its cpus is refused without `measured_ack`.
4. **Smokes** are FIFO on the lane, one at a time. They never produce COMPLETE: a `.complete` without a grant is rejected.
6. **Hold budget (operator decision 2026-11-05, "Gate at a budget").** Strict priority holds stay for the top row, but every tick charges the idle the hold leaves (held cores still free / 24 + 1 if the held gpu is free, x tick hours) to a per-UTC-day ledger. Once it reaches `HOLD_BUDGET_QH` (default **12 q-h/day**; the shadow sim prices holds at 1.5-9.9 q-h + <=~1 gpu-h/day, so it binds only on outlier days), the hold is still reported (`budget_qh=…/12 SPENT`) but no longer binds, and lower rows backfill. It replaced `FILE_OWNERLESS_S`: owner-less `.ended` routing now reuses `SMOKE_DEADLINE_S` (both were 1200 s), so the tunable count stays 8.
7. **SMT siblings for timing rows (main-inf22 report, 2026-11-05).** A row may declare `timing: true` (legacy `block-timing-*` maps to it). A timing CPU grant holds the SMT siblings of its cores. Cores 88-95 have siblings 184-191, the MI210 host lane, so a timing row may use them only with `gpu: exclusive` (gpu-quiet); otherwise `validate` refuses a concrete q3/88-95 placement and `admit` strips 88-95 from class/any-N options, so `any-quarter` lands on q0-q2 (or waits). Correctness rows are unaffected; the gitnexus-q3 coexist shape (72-87, never 184-191) stays legal. Origin: iqk-q8-prefill-ab-r6 on q3 shared 8 of 24 decode cores with c6-gpu-27b-identity's host threads during a 27B reload; requests ran 20-70% slow (incident fixture `test_7`).
5. **Shadow** is read-only, enforced by a `sys.addaudithook` write guard under the flags dir. Live dry runs count as occupied tokens. Each id is logged once.

## Shadow week (starts 2026-11-05)

## Switch-over criteria (all must hold over 7 consecutive shadow days)

1. Zero shadow crashes (`SHADOW-ERROR`) and zero write-guard refusals.
2. No shadow grant violates a two-sided invariant against the live snapshot.
3. Shadow idle token-hours with runnable rows ≤ live, each day, and within 0.5 q-h / 0.25 gpu-h of budget.
4. Every live/shadow disagreement in the daily diff is reviewed. Each is classified as shadow-correct, live-correct (→ fix rowflow2 + add a fixture) or spec defect (→ owner republish).
5. Every not-done row maps (`map-report` unmapped-not-done = 0) or has been republished.
6. The gaps above are closed, with tests.
7. The cutover is one deploy at a grant-quiet boundary. In-flight grants are honoured. The P3.3 deletions land in one commit.
