# Prospective KPF-17.4 plan-binding adapter

`binding.py` is a standalone candidate for a future caller of the existing `kpf174-oracle-preflight-20261105` guard. It requires separately trusted SHA-256 pins for the exact plan and guard bytes, binds a nonempty unique set of cell IDs and each cell's group and junction to the plan, rejects duplicate JSON keys and duplicate planned geometry, and calls the guard on a private snapshot before invoking the unchanged judge. The plan defines one launch role and geometry. The guard verifies arm cardinality, source slot, controls and the partial-noop pruning scope. Five model-free tests exercise successful invocation and fail-closed mutations; run with `python3 -m unittest discover -s docs/reports/kv-cache/kpf174-plan-binding-20261105 -v`.

This candidate is **not wired or published**. It does not predeclare or select a model input, establish that a plan is authorized, bind the plan digest to an external authority, validate full launch-matrix coverage, prove controls are independent or layout matched, prove DSO custody, or judge output correctness. The caller must supply trustworthy independent digest pins; executing guard bytes is safe only when that pin is trusted. No historical or exposed cell was replayed or regraded, and no prior result changes. A prospective runner still needs review, runtime sealing and its own qualification before use.
