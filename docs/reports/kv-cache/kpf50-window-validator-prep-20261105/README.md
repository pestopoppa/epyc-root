# KPF50 offline window receipt preparation

`validate.py BUNDLE --expected POLICY --expected-sha256 HASH` reads only bundled
artifacts. Exit 2 refuses missing/malformed evidence; exit 3 means UNKNOWN native
physical binding. Exit 0 is reserved for explicitly synthetic controls. No native
PASS, qualified validator, performance result, or >=20% verdict is available.

The predeclared source, four-window order, four >=60000-token child forks,
4x80000 context shape, first qualifying native log step, uniform decode/verify,
input/position/sequence joins, mask/layout, enclosing draft and iteration,
calibration brackets, raw separate profiler clock witness, nonoverlapping dispatch
and two during-step own-PID residency records are checked. Exact expected identity
policy covers executable, model, drafter, DSOs, device, argv and prompt hashes;
its seal must come from a separately reviewed policy. Dispatch names/families
must be supplied by that policy, never discovered from observed timing. There is
no invented clock uncertainty cutoff: ambiguous dispatch containment is refused.

Limit: maps, residency, child/shape and freshness records currently use a strict
normalized JSON carrier; their hashes establish byte custody, not physical truth.
No reviewed raw /proc, KFD/VRAM sampler, native fresh-window or shape provenance
parser is available here. Consequently every otherwise consistent native window
is UNKNOWN. Actual per-window calibration is checked independently of the smoke
witness; no global witness substitutes for the window calibration. Full-window
comparison must additionally match step `inputs`, `masks`, phase, draft-slot count,
identity and dispatch-family sequence across all four independent windows.
Matching these cannot establish K/V value identity. Cleanup is an independent
supervisor obligation and is not certified by this validator.

`vendor/` snapshots the existing reviewed select_step, HSA offset calculation,
and raw clock-smoke verifier from the prospective research evidence scripts.
`controls/` contains a clearly synthetic positive-shaped bundle, a separately
sealed policy, mutation specifications, and SHA-256 seals. `make_controls.py`
only generates these artifacts; controls were not run. Mutations include missing
clock/log evidence, wrong candidate/order, incomplete exposure, and native UNKNOWN.
No target access, compute run, test execution, publication or shared repo edit
was performed. This package is preparation only; it does not create native evidence.
