# Historical source impact — fresh instrumented index

A private snapshot of the installed GitNexus tool records each native scope skip and each unreadable scoped input without changing the skip decisions. The full run seals and checks the tool snapshot, scripts, Node executable and detached historical source at start and end; builds a fresh index; records each skip path and large-file exclusion; requires scope counters to match the skip identities; accepts only witnessed empty-file scope skips; verifies the graph source hashes; and captures both native upstream impacts. HIGH/CRITICAL stops for review. Any unknown skip or source/tool drift refuses full coverage.

Only this new run can establish its own skip identities. This does not retroactively identify the anonymous R2 skip, bind a historical task or adjudicate a model result. The source clone and private analyzer are experimental; production trees and the system installation remain unchanged. Snapshot start/end checks do not exclude a same-UID writer temporarily changing bytes and restoring them between checks. The four-CPU publisher smoke uses only source-reference progress, not full indexing or impact coverage.
