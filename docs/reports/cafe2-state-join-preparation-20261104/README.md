# Prospective CAFE-2 source-authored snapshot join controls

`join.py` is an isolated, unintegrated prototype. It refuses any arm without its own source-authored `state_sha256`, snapshot byte length, bounded in-root snapshot path and matching raw bytes. It requires matching source/binary/model/library declarations, actual declared thread counts, equal prompt/boundary/draft IDs, all 55 fixed ordered cells, true per-cell restore equality and state digest, 40 distinct complete expert layers with consistent event window/rep/cell/position, tensor name/shape/strides and full routed IDs, and callback-free finite timing. It rejects duplicate JSON members, nonfinite constants, missing/cutoff/unreaped arms, type confusion and conflicting identities.

A result means only that snapshot bytes and source-authored declarations match; it cannot authenticate arbitrary producer claims, loaded DSO mappings, graph callback correctness, the timing floor, a cost decision or a belief claim. No state digest is inferred for historical records, and old native source without a producer-native digest fails UNKNOWN. The current native owner must emit and bind the original digest, byte count, snapshot and native identities before any future run; this prototype does not modify the active writer or add a grading rule.

`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_join` passed 15 synthetic controls. These are parser/structural controls, not native model, CPU timing, callback or scientific validation. The schema is a prospective producer-envelope proposal and must be reconciled with the owner's actual source before integration; it does not establish that any current producer conforms.
