# CAFE-2 verify-cost build prerequisite

Source is v10 ffc1bac82eeca6f9099e1ccd9ba49703c460a115 plus one CMake integration patch. This row compiles the proposed target-verification executable only. Smoke compiles the actual candidate object; full row links all runtime libraries. No model is loaded by this build row and it cannot close CAFE-2.

The candidate obtains eight real MTP draft tokens from the target via the existing bridge. It saves target state after prefill/drafting and before any verification; before every measured width it restores exactly the same state, reserializes, and requires byte equality. Widths 1..9 share one boundary and one draft-prefix chain. It times only synchronized target llama_decode. Five fixed interleaved schedules include width-1/width-5 repeats, for 55 raw records. Nonfinite logits/timings, elapsed time below 1 microsecond, incomplete width, or state mismatch refuse a valid result. Missing cells are UNKNOWN, never zero.
