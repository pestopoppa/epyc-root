# SR-8 independent held-out edit diagnostic

One fresh server per arm/request; the first smoke unit is a current-DFlash2 arm so qualification exercises count extraction. Five interleaved three-arm blocks over t3,t4,t5,t3,t4. Exclude t2 because the prior native run and qualification exposed it. These three prompts were not observed in the reviewed prior SR-8 run/smoke inventory; this is not a claim of full historical disjointness. Repeated tasks use newly started servers, never the same live server. Pre-rendered/tokenized prompt bytes, model/binary pins and five blocks are frozen before publication.

Per speculative request take exact draft_n and draft_n_accepted from response timings, bind to exactly one same-slot native info log line with identical counts, and derive the verifier-round count only if exactly one positive integer <= drafted is consistent with the printed %.2f mean under an inclusive 0.005000001 rounding interval. Preserve raw response, slot/task log, bounds and candidate; zero acceptance, missing/duplicate lines, counter mismatch, or more than one candidate is UNKNOWN. No rounded or estimated count is silently treated as exact. This parsing rule is declared before any new exposure.

Require all five complete paired blocks, canonical edit checks and in-request GPU residency. Compute paired lookup/current-DFlash2 geometric mean decode speed and separately weighted accepted length. >=1.5 is only a candidate signal, no routing change or noise-floor claim; incomplete, malformed, unmatched or ambiguous evidence is UNKNOWN and stop-on-futility with no adaptive extension. This is a new held-out experiment, not an amended verdict or reset of the prior failed row.
