# Private API isolation proof

The pinned native API reached `/health` with an inherited loopback listener after private-write and socket-creation denial checks. It shut down and its owned PID was absent; exit code 1 followed normal shutdown when seccomp denied Uvicorn’s signal re-raise. The health response was degraded with zero models loaded.

This is an isolation/lifecycle control, not an EvalTower result or an inference run. Denying new sockets also blocks the API’s dynamic backend HTTP connections; Landlock’s port rules alone do not prove destination-IP isolation. The B4c row is not ready until the actual API/backend/EvalTower lifecycle is isolated and qualified.

A later [broker control](broker-v6-result.json) installed the filesystem and raw-network denials before importing the API, rejected ten malformed or non-allowlisted targets, and made a native health probe over a brokered connection to an owned loopback dummy server. The API's source-prior production ports were refused. This control used in-process ASGI ingress with no lifespan, REPL, model, inference or scoring; it does not qualify the full dynamic backend lifecycle. An earlier v5 broker probe imported the API before sandboxing and must not be used as evidence of isolated import.

The subsequent [v7 control](broker-v7-result.json) exercised native lifespan, private dummy-backend health probes, and loading the 50-question EvalTower suite with denial checks before API import. Its health `models_loaded=1` counts the HTTP fixture: no model was loaded and no evaluation ran. The native attestation tried a shared temporary path and was denied; no REPL backend roles were constructed. It ran against a temporary copied source directory, which was subsequently removed and replaced by a detached worktree; the proof was not rerun against that worktree. This remains partial isolation evidence, not a qualified B4c row.

The [v9 control](private-control-v9.json) used a clean detached source worktree, routed the attestation to private scratch, and exercised a native request-primitive constructor with a private dummy backend. It also showed that the health probe's source-defined stack-prior default ignores the existing private-path environment override; default production-named endpoints were denied by the broker. A [prospective patch](health-private-path.proposed.patch) reads that override while preserving the old path when unset or empty. Eight [offline path-resolution controls](health-patch-tests.json) passed with fake probes and no network calls. The three affected health functions have LOW pinned-index upstream impact; this patch has not been applied to maintained source or qualified with a model-backed evaluation.

The [patched-worktree control](patched-native-control.json) exercised native lifespan and health against an owned HTTP fixture after filesystem and network denials were active; nine native route tests passed. The health response's `models_loaded=1` counts that fixture, not a model. The private worktree carried only the health patch, and the maintained source remained clean. No real EvalTower evaluation or model inference ran.
