# Declared scratch-root KEEP protection

`build_plan` now represents a marked declared plain scratch root as a preserved candidate instead of enumerating removable children. The four existing in-directory marker names and the existing sibling `.epyc-keep` form are honored. Explicitly overlapping roots/globs, the marker file itself, and ancestor removal candidates containing that marked root remain preserved. Path-separator-aware realpath checks leave unrelated siblings independent. Unmarked roots retain existing clone/worktree/evidence/process/reference and trash-first gates.

`apply_plan` rechecks declared root markers before constructing removal sets or calling the worktree/trash removal paths. A marker created between planning and applying protects previously removable plain and worktree entries. This is a phase-boundary recheck, not an atomic guarantee against markers created after that check.
