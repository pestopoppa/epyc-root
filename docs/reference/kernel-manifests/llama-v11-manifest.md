## How to keep this current

Every fold, keep or exclusion edits this manifest **in the same commit** (operator directive 2026-10-20: features and performance improvements are folded ONLY into champions; nothing is promoted to production piecemeal; the next production kernel upgrade must be significant). A fold changes the row's status and sha; a new keep adds a row; an exclusion records its reason and evidence; a rebase updates the sha and the base. A champion move, a branch push or deletion, or a change of owner is a manifest edit too. A row never leaves the table: superseded rows stay with a pointer to their successor.

Rules for the cells: gains are copied from the cited artifact, never recomputed; a per-keep AutoKernel percentage is a 5-pair screening number, not a marginal or additive effect (aggregate CH-16: 36 per-commit claims compounding to +171.7% against a measured block effect of +8.524%). The presence gate is what a candidate build must pass to prove the row is still in it.

Gate codes. **G-ANC**: `git merge-base --is-ancestor <sha> <candidate>`, or `git cherry <champion tip> <candidate>` shows the commit as `-` when the candidate rebased it. **G-AK**: CPU `test-backend-ops -b CPU` with `GGML_IQK=1` (MUL_MAT, MUL_MAT_ID, FLASH_ATTN_EXT all pass) plus greedy identity candidate == champion, plus the named `serving:` bench cell paired against the candidate without the keep. Every candidate also needs `verify_ggml_linkage.sh` PASS and a CPU and a GPU store build of the same commit (single-champion invariant).

Status words: **IN** in champion @ sha; **IN-C** in candidate C (folded, awaiting gates and CAS); **PEND** pending fold (includes tracked-but-unfolded and un-triaged); **CAND** candidate only, not built; **EXCL** excluded, with reason; **SUPER** superseded.

Sweep sources: `handoffs/active/autokernel-champion-aggregate.md` (all fold ledgers, DO-NOT-FOLD ledger, CH-18, EmbeddingGemma 2), its completed ledger, `git -C /mnt/raid0/llm/llama.cpp log ffc1bac82..dd3d9721c` (42 commits), every `fork/experimental/*` branch plus local-only `experimental/*` branches classified with `git cherry` against `dd3d9721c` and their commit messages and handoff notes, and today's guard-bands, AKX-ALL-26 and Q38-T10 notes.
