## How to keep this current

Every fold, keep or exclusion edits this manifest **in the same commit** (operator directive 2026-10-20: features and performance improvements are folded ONLY into champions; nothing is promoted to production piecemeal; the next production kernel upgrade must be significant). A fold changes the row's status and sha; a new keep adds a row; an exclusion records its reason and evidence; a rebase updates the sha and the base. A champion move, a branch push or deletion, or a change of owner is a manifest edit too. A row never leaves the table: superseded rows stay with a pointer to their successor.

Rules for the cells: gains are copied from the cited artifact, never recomputed; a per-keep AutoKernel percentage is a 5-pair screening number, not a marginal or additive effect (aggregate CH-16: 36 per-commit claims compounding to +171.7% against a measured block effect of +8.524%). The presence gate is what a candidate build must pass to prove the row is still in it.

Gate code **G-ANC**: `git merge-base --is-ancestor <sha> <candidate>`. Every candidate also needs its own `LD_LIBRARY_PATH` proved with `verify_ggml_linkage.sh` (three ggml generations coexist) and `scripts/session/verify_speech_kernels.sh`.

Status words: **IN** in the production base (a must-carry); **PEND** pending; **CAND** candidate only; **EXCL** excluded; **SUPER** superseded.

Sweep sources: the two production trees, `/mnt/raid0/llm/worktrees/{qwentts,whisper}-threadpool-20261020` (inspected read-only: `git status`, diffs, file mtimes, process list), `handoffs/active/conversation-stack.md` (speech-kernel sections, CS tasks), `artifacts/qwentts_threads_20261020/`.

## Proposed speech champion branches (NOT created)

Mirror the llama.cpp workflow: a standing aggregate that every speech improvement folds into, never production piecemeal.
- `champion/speech-qwentts` in `qwentts.cpp`, cut from `production-speech-v1` (`2c1b5182e`). The barrier and threadpool work lives in the **ggml submodule** (`pestopoppa/ggml`), so it needs a paired submodule branch, for example `champion/speech-qwentts-ggml`, cut from `b86f6602`, with the superproject pointer bumped by the fold commit.
- `champion/speech-whisper` in `whisper.cpp`, cut from `production-speech-v1` (`b30737922`); ggml is vendored in the tree, so one branch suffices.
- Folds go through a fold ledger (a section in `conversation-stack.md` until a speech aggregate handoff exists), each fold CAS-moves the branch, pushes to the `fork` remote and edits this manifest in the same commit. Any fold must keep both gfx90a patches (rows 1-3) and re-prove linkage.
- First fold candidate: the persistent-threadpool / non-spinning-barrier work, once its owner commits it and records a correlation and ms/frame result.
