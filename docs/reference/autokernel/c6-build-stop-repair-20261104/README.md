# C6 diagnostic build stop-handling prototype

Reference-only repair for the `akx-c6-n4-cublas-build-20261104` launcher. Its original job blocks in `subprocess.run` during configure and build, so it cannot react to STOP until that command exits; its SIGTERM handler unwinds without explicitly terminating and reaping the child. The separate prototype checks STOP and deadline while each command runs, launches an owned process group and terminates, reaps and checks it on every exit. An unreaped group fails closed. The live row and its sealed packet were not modified.

Run `python3 -B docs/reference/autokernel/c6-build-stop-repair-20261104/test_job.py` from the repository root. Tests exercise normal completion, nonzero exit, and STOP with an owned child and descendant, and escalation to SIGKILL when the child ignores SIGTERM. They do not exercise a full CMake build, engine deadline, external hard-kill or real-grant cleanup. In particular, an uninterruptible process or a lingering zombie can cause the group check to fail; no build or GPU correctness result is claimed. This snapshot must be integrated into a newly sealed, source-bound packet and independently qualified before it is used in a successor row.
