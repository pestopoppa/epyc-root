# C5 mapped-owner receipt integrity draft

Private model-free review copy. `run.py` remains unconditionally disabled. No floor, placement, quiet-host or continuous-custody admission follows.

Changes: phase records of each launch must name the same process birth `(boot_id, pid, start_ticks)` and all 48 births must differ at binding and replay. Sampled placement windows must use one boot clock and be nonoverlapping and ordered warmup, measurement, then next launch; this checks retained observation windows, not precise request or process lifetimes. The frozen request's ordered prompt/body digest is recomputed at bind; replay requires independently supplied expected prompt ID, body hash, ordered request digest, and complete expected calibration plan, compares every phase to the expected request and rederives each launch's pair/arm from the plan. Runtime capture checks `/proc/<pid>/exe` inode/device against the server mapping; replay checks the recorded executable identity against the mapped server. Recomputed unkeyed hashes do not authorize or authenticate any artifact.

`verification_pin.prepare` verifies the pinned manifest and native source hashes, re-derives and compares the actual frozen request bytes using the native manifest and resolved recipe, verifies the native request digest, and writes a new exclusive fsynced pin containing a freshly drawn native seeded 24-pair plan. The disabled private runner prepares it during context construction before calibration. `use_pinned_plan` checks the sealed bytes, native sources, request and recipe, and forces the native calibration's single schedule draw to that exact plan; incompatible invocation or missing/extra draws fail closed. A model-free test exercises the actual native calibrator with its 48 measurements stubbed.

`complete.py` requires `input/verification-pin.json`. This file is a consistency record, not an independent attestation: before enabling any successor, the owner must ensure trusted, externally sealed pin custody and bind the pin and all producer/native dependencies to the sealed launcher and full-run attempt; the source and frozen recipe/manifest must be independently approved. The temporary native scheduler override assumes exclusive use of that module in the process; concurrent calibration is unsupported. This draft remains disabled and does not qualify the build, source custody, sampler, request timing, scheduler/quiet preconditions or a floor. `/proc` maps and exe remain point-in-time checks with race limits.
