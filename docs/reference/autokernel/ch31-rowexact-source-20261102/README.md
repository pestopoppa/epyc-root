The source narrows the possible dispatch change. `ggml_compute_forward_mul_mat` first attempts IQK if built in and enabled. The IQK dispatcher admits only supported weight types and F32 activations; Q8_0 additionally needs `GGML_IQK_Q8_0`. If admitted, its small-batch setting can select repeated single-row kernels instead of a multi-row kernel. If IQK falls through, the llamafile-enabled path checks contiguous `src1` and, for eligible `1 < ne11 <= N`, skips tinyBLAS and goes to generic vec-dot. The corresponding disabled setting allows the tinyBLAS attempt, subject to its own acceptance checks. C5 asserts `ne1 == ne11`, so the observed output shape implies `ne11=4` for this node; `N=0` fails and `N=4` satisfies the numerical threshold. These are conditional source paths, not a recorded runtime branch trace. The environment intervention also affects other eligible graph nodes.
