# CH-26 observed scheduler interval projection

`intervals.py` consumes normalized `sched_switch` dictionaries from the neighboring `ch26-trace-normalizer-20261105` prototype and projects each bracketed per-CPU chain into half-open intervals clipped to a request window. It totals time associated with caller-supplied owned thread IDs, idle (TID 0), and all other observed TIDs, and flags owned intervals outside caller-supplied allowed CPU sets. It rejects malformed or incomplete brackets, nonmonotonic or discontinuous switches, and simultaneous observed execution of the same nonzero TID on two CPUs. Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -v -s docs/reference/autokernel/ch26-sched-intervals-20261105` from the repository root; six synthetic controls pass.

This is an offline component, not a live observer or floor-admission rule. Trace completeness, loss, CPU coverage, clock alignment, PID birth identities and the owned/allowed inputs are unverified. In particular, absent switches can preserve an apparently consistent chain, foreign runtime need not be CPU contention, and interrupts are not captured by this projection. A bracketing switch is required on each side, so a quiet CPU may be rejected even if the source were complete. Every result explicitly marks coverage and loss unknown, placement and contention unproven, and measurement admission none. No native measurement or noise floor follows.
