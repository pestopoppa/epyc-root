The original harness imports `owner_hook` from the wrong directory and omits the required `request_context`. This copy adds the native directory to the import path and supplies a synthetic diagnostic context to `RequestCapture`. The all-zero digest is a synthetic marker, not a real request digest.

`python3 -m unittest -v test_repair` checks the repaired import and context passed to the owner. The copied native modules are the isolated prototype dependencies; they have not been shown to provide authenticated request boundaries or continuous coverage. No inference or native perf capture was run by these unit tests. The original requested C5 floor, actual observation overhead, source authentication, and full native functional qualification remain open.

A proposed six-checkpoint row was withdrawn because its five-minute duration was not supported by a distinct measurement question. Its publication attempt failed at smoke before executing the job: the launcher used relative paths in its source-seal check. No row was published.

The capture-worker import closure now shares the Linux `PERF_EVENT_IOC_ID` constant through `kernel_counter.py`; an isolated-interpreter import test covers the complete worker import path. `native/ring_archive.py` is a separate experimental compact archive and replay verifier: it retains only the logically occupied ring bytes with absolute head/tail, ring size, event ID, a chained digest and a byte quota. It checks per-event continuity and fails closed on lost, malformed, truncated or overrun records. Empty ring bytes outside the captured window are deliberately not retained. Synthetic tests cover wraparound, continuity, explicit loss, quota, tampering, truncation and overrun.

The isolated experimental worker now spools compact records as it drains, publishes an event-ID-bound chained archive receipt with its terminal counters, and the owner replays exact source identities, terminal head/tail and tracepoint payloads before accepting the unproven receipt. The worker removes incomplete archives and closes owned sockets on setup and lifecycle failures. Synthetic tests cover receipt mismatch, duplicated or absent terminal sources, archive setup failure and abort cleanup; they establish no live trace, cross-source coverage or observer overhead. Compact byte quotas still fail closed on excess, so a fresh bounded native functional qualification is required before any C5 measurement. Source FD/kernel semantics, request meaning, placement and contention remain unproven; no noise-floor claim follows.

Receipt publication rolls back its own linked result if directory synchronization fails, with inode checks to avoid removing an existing or replaced path; this check and unlink assume the private output directory is not concurrently modified. A drain thread that fails to join retains its archive descriptor for worker-process exit instead of closing it concurrently. The perf-ring reader also rechecks the producer head after copying and refuses tail advancement if overwrite is detectable; this is not proof of complete delivery or kernel coverage. Fault-injection and mocked ring tests cover these failure paths.
