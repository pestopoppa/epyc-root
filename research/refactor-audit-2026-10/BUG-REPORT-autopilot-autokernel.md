## How the bugs were found

1. **Static evidence** over all three trees: an AST scan (function length and cyclomatic complexity,
   import-time side effects, swallowed broad excepts, duplicate function bodies, private cross-module
   imports), vulture dead-code candidates, extended ruff statistics, and per-file git churn.
   Summaries: [`metrics/`](metrics/).
2. **One deep finder per code unit** (17 units: A1-A6 orchestrator core, B1-B5 autopilot, C1-C6 AutoKernel)
   across seven dimensions: best practice, documentation, modularity, performance, debuggability, tests, bloat.
3. **One adversarial verifier per unit**, defaulting to *refuted* unless it could confirm the finding
   first-hand (open the cited lines, run the greps across all three repos, reproduce where possible).
4. **A production-safety lens** on severity ≥ 4 findings (autopilot units only; the orchestrator-core and
   AutoKernel safety passes were cut off by a usage limit on 2026-10-07).

**Verification caveat:** AutoKernel units C4 (evaluator/execution), C5 (release + top level) and C6 (tests)
were never adversarially verified (usage limit). Their findings are marked `UNVERIFIED` and every fix
package re-verifies them first-hand before acting.

## How fixes are being made

Each work package runs in its own git worktree: an implementer re-locates each finding at the current
HEAD (the audit is from 2026-10-07; line numbers have drifted), writes a regression test that FAILS on
the current code before fixing a bug, commits one finding per commit, and an adversarial reviewer then
re-checks the package diff. On 2026-10-24 the run was stopped by the operator part-way through wave 1.

**Status legend.**
- **fixed, unreviewed**: implemented with a regression test and targeted test runs by the implementer, on
  the named `refactor/*` branch, rebased on origin/main 2026-10-24. **No adversarial review has run on any
  package yet.** Review before merge.
- **committed, unreviewed, no test report**: committed by an implementer that was cut off before it
  reported its test runs (O7, O6 stage 2). Treat as untested.
- **WIP, unreviewed**: a partial fix committed so it would not be lost; its commit message says what is
  missing. Do not merge without finishing it.
- **open: planned in <package>**: not started; the package is defined in `packages/wave1.json` or
  `packages/wave2.json`.
