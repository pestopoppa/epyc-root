# ggml : vectorize ggml_vec_exp_f32

Open, head 6c855af36156079be907d4986123f0c560a104be. Adds AVX512F+DQ, AVX2+FMA and other platform paths using existing vector exponential with scalar tails. Author reports 3.1–6.5% baseline slowdown for multi-token op cells (16 pairs each) and 1.5–2.7% single token (40 pairs); no model-level gains established.

[Primary source](https://github.com/ggml-org/llama.cpp/pull/33077)
