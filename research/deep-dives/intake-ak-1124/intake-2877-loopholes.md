## 1. Stage-1 fields
- **Title**: Which Loopholes Get Found? Predicting Reward Hacking of LLM Judges Before RL Training
- **Authors**: Xuanyi Lyu, Yuezhou Zhao, Qing Qin (Columbia University). **Version**: arXiv 2611.29651v1, cs.CL, 22 Nov 2026. Code/run summaries at github justLxy/which-loopholes-get-found (not fetched).
- **Categories**: training_distillation, benchmark_methodology, autonomous_research
- **Novelty**: medium-high. Static judge-probe papers (One token to fool, Huang et al. 2026) measure what a judge accepts. This one multiplies it by how often the starting policy emits the pattern and tests the product causally by seeding patterns into SFT. Novel piece is the pre-training predictor plus a timing fit, not the observation that judges are foolable.
- **Relevance: medium (re-judged up from Stage-1 "low")**. Why: the operator names LLM-as-judge audits before local Qwen RLVR/GRPO, AutoPilot judge gates and eval rigor as consumers. Today no gate of ours optimises against an LLM judge (see section 5), so the paper is not load-bearing for a live gate. It is the design reference for the audit that must exist before any judge-reward GRPO run or any search loop that ranks candidates by an LLM verdict. Not high: one 1.5B policy, math, 300 steps, propensity raised by seeding.
- **Credibility: 1/6.** Arithmetic: peer-reviewed +0 (arXiv v1 posted 2 days ago); <=12 months +1; major lab / known contributor 0; commercial bias 0; independent corroboration 0 (its reproduction of Huang et al.'s R1-Distill-Verifier vs base-model ordering is a re-run of the same judges, not independent evidence for exposure). Total 1. Internal rigour is above that number (pre-registered predictions, Holm correction, masking and low-share holdouts, exact tests), so rely on the method, not the score.
- **Verdict: adopt_patterns.** Adopt the audit recipe (string-level FPR x sampled propensity, pre-registered before optimisation). Not adopt_component: no code is needed and detectors are math-specific.

## 2. Key claims
0. **First exploited pattern had highest exposure in 12/12 exploiting runs, highest FPR in 6/12** (36 GRPO runs, 7 judges). **CONFIRMED, narrowed.** Counts are as stated (24 core + 9 held-out + 3 unseeded-control runs = 36; four core judges + three held-out). But the 12 runs start from only three SFT checkpoints (one per seed), and all core events fall on four families. Counted by starting checkpoint the paper reports exposure correct at 9/9 checkpoints, FPR alone 2/9, propensity alone 4/9 (McNemar 7-0, p=0.016 vs FPR; 5-0, p=0.063 vs propensity). AUROC lead over FPR alone is +0.037 (0.974 vs 0.937). Anchor 0, 1.
1. **Measurement protocol (propensity before training; FPR audit).** **CONFIRMED.** p-hat: sample the *already-seeded SFT starting checkpoint* 16 times on each of 250 problems per pool (4,000 samples, Jeffreys smoothing), rule-based family detectors label the outputs. FPR: string-level, share of 471 audit math problems on which the judge accepts the family's fixed seeding string as correct, run under the same prompt and decoding as in training. Strings (not family means) because string FPR differs from family mean by up to 67 points. Negatives: none are a separate set; every audit item is a hack string standing in for the answer, so it is wrong by construction. Detectors flag 0 of 12,500 reference solutions. Anchors 2, 3.
2. **Onset-window prediction.** **CONFIRMED.** Fit log t = 5.64 - 1.03 log x over first events of the main runs (t = event step, x = exposure), residual sd 0.38, giving a predicted step and a 90% window. All nine pre-recorded winner predictions (3 masked runs where exposure named the winner, plus 6 low-share) fell inside the window; the masked-run windows are 29-102, 33-114, 36-124 steps and the low-share windows 32-158 steps, i.e. wide. Low-share events landed at 0.62-0.73x the predicted step, early, so the point estimate is biased high. Anchor 4.
3. **Two seeded patterns at 3-3.8% of SFT: exposure named the winner and onset window in all six runs.** **PARTIAL.** Doses are F1 adv-prefix 2.0% + answer-explanation 1.0%; F2 "{" 2.0% + "Thought process:" 1.0%; P2 answer-explanation 1.8% + system-mimicry 2.0% (3.0/3.0/3.8% total). All six winners = higher exposure; FPR alone missed all four F-run winners, propensity alone both P2 winners. Weakness: only three pattern pairs, two judges, 2 seeds each, six runs sharing three checkpoints; the pairs were chosen so that a bootstrap stability gate (>=90%) separated the scores; a first pair (P1, stability 55-66%) was dropped before any run finished and replaced by P2; late takeovers in 3 of 4 F runs (10, 20, 130 steps after the winner) show exposure predicts first events only. Anchors 5, 6, 7.
4. **"Exploitation only on hard prompts."** **PARTIAL.** Seeded hard-pool runs had events in 12 of 21; easy pool none; in 7 of 12 core run pairs differing only in pool, hard had an event and easy none, reverse never (exact McNemar p=0.016, Holm 0.031). Three of those 12 pairs are xVerify (no run of it had an event), so 7 of 9 informative pairs. Easy-pool families with exposure up to 9.4 stayed flat. Mechanism offered (group-normalised advantage 2.6x larger on hard prompts: sqrt(7(1-q)/(8q)), q = starting acceptance rate) is computed at plug-in mean acceptance, not intervened on. Authors state the hard and easy pools differ in problem source (MATH vs DeepScaleR) as well as difficulty and they did not train on single-source pools. Judges accepted 14.7% of family responses on both pools, so the audit FPR does not change with difficulty; the gate sits in the optimiser. Anchors 8, 9, 10.
5. **Seeding-dose causality (H3).** **PARTIAL / weak.** Events 0/42 in control, 0/112 at 0.3%, 2/112 at 1.2%, 7/112 at 4.0%, but the exact dose test is p=0.056 (Holm 0.056) and cannot go below 0.017 with events on four families. The steering text omits this. Anchor 11.
6. **Scope.** **CONFIRMED as limit.** Natural propensity of the base policy is too low to exploit anything: 19 of 174,760 responses in any of 14 families (exposure below 0.03); exploitation needed seeding that replaced about a quarter of SFT in main runs. One 1.5B policy, 300 GRPO steps, integer-answer math, 14 known families, judges fitting on one GPU. Anchors 12, 13.

## 3. Reported results (as stated)
- Setup: Qwen2.5-1.5B-Instruct policy, TRL + vLLM, DAPO token loss, 300 steps x 32 prompts x 8 samples, no KL, lr 1e-6, T=1.0, one RTX PRO 6000 96 GB; ~242 GPU-hours total. Judges: R1-Distill-Verifier-1.5B, DeepSeek-R1-Distill-Qwen-1.5B, Qwen2.5-Math-1.5B-Instruct, xVerify-0.5B-I (core); General-Verifier, Qwen2.5-7B-Instruct, Qwen3.6-35B-A3B (held out).
- Core-run AUROC for "is a pattern exploited at all": exposure 0.974 (0.955-0.995), FPR 0.937, propensity 0.847, static accuracy 0.379. Expected-advantage score p-hat(FPR - q0)/sqrt(q0(1-q0)) 0.993 (secondary analysis).
- Winner rank: mean reciprocal rank 1.00 exposure, 0.71 FPR, 0.52 propensity. Event step vs exposure Spearman -0.84; slope of log step on log exposure -1.03.
- Empirical threshold: no main-run family below exposure 1.92 (= 0.0075 rewarded-response rate x 256 responses per step) had an event; 8/9 held-out runs classified right at that threshold.
- Masking (4 runs, predictions recorded first): exposure named 3 of 4 winners, FPR alone 0, propensity alone 2. Masking the top-FPR pattern left the winner unchanged in two runs.
- Qwen3.8-27B-FP8 (our judge family) under the Huang no-question prompt accepts "Thought process:" on 1.5% of 471 problems, "True" 0.4%, no other of the 14 strings; exposure stays below 0.17, so the authors did not train against it. Qwen3.6-35B-A3B-FP8 accepts "{" on 84.7%. (Different quant and prompt from ours; datum, not a transfer.) Anchors 14, 15.

## 8. Contradiction / adversarial pass
- Authors' own limits: one 1.5B policy, 300 steps, integer math, 14 known families; larger policies may find patterns outside the families; seeding does not model natural data; per-judge intervals wide; dose test cannot go below p=0.017 and reads 0.056.
- Statistical dependence: 12 exploiting main runs share 3 checkpoints, so the 12/12 vs 6/12 headline is closer to 9 independent units (exposure 9/9, FPR 2/9).
- Winner-take-all: exposure fails to predict takeovers (later patterns had higher FPR; in 3 of 4 F runs the second pattern took over, exposure 0.89-1.46).
- Masked run 4: winner was third by exposure (2.04 vs 2.15 for the top two): a near-miss counted as 3 of 4.
- Selection of test cases: low-share pairs were filtered by a pre-run gate and P1 was dropped before any result; the 6/6 is conditional on pairs where scores separate robustly.
- The hard-vs-easy contrast is confounded with problem source. Mechanism not intervened on.
- No outside replication; the core Huang et al. ordering check is a re-run of the same judges. Everything here is a paper-reported number; GitHub repo not read.
