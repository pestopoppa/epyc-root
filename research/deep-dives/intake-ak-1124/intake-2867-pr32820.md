## 3. (a) Exact ggml.h contract text
Upstream @ 7778de0 (ggml/include/ggml.h:2429-2432) and in-house @ 98ff8a42a (ggml/include/ggml.h:2694-2698), identical:
```
// the output packs the attention scores [S_v, H_v, n_tokens, n_seqs] followed by K state
// snapshots, most-recent first (slot 0 = final state, slot s = state s tokens back). K == 1
// keeps only the final state; when n_tokens < K only slots 0..n_tokens-1 are written.
// when n_tokens > K only slot 0 is guaranteed; backends may leave slots 1..K-1 unwritten.
```
Note the contract is silent on n_tokens == K (all K slots written by the first rule; the test restriction uses `n_seq_tokens > K`, so n == K is still fully compared). The in-house header additionally documents the replay and tree variants (ggml_gated_delta_net_ext / _tree) which are fork-only.
