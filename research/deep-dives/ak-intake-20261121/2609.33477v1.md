## What is logged and what replay recomputes
Logs the input hidden state of the first linear-attention layer of each group (post the preceding full-attention layer), BF16, at anchor density 1/16 (dense layout: last 4 rows of every 64-token page), written by in-CUDA-graph indexed copies. Replay runs only the linear-attention layers of each group (convolution + gated-delta recurrence, with MLPs: FrontierReplay says it re-runs MLPs too) from a zero/initial state over the last k anchors, never the FA layers. The anchors are NOT the keys/values/g/beta; those are recomputed from hidden states. Because anchors are sparse (not contiguous tokens when ρ<1), the replayed sequence is a subsampled stream, an extra approximation beyond truncation.

## Safety for EPYC use
Not safe for exactness gates. The paper never measures logits, KLD or greedy token identity; it measures task score ratios (F1/ROUGE/exact-string) where a 1% score drop can hide many changed tokens. Speculative verify with an approximate target state is still lossless relative to that approximate target, but the target is no longer the model we gated on, and DFlash2/MTP acceptance and Q38FN KLD gates would silently move. Also A3B greedy decode is already nondeterministic on MI210, so an extra systematic shift would be hard to separate from noise.

The only independent measurement is FrontierReplay (intake-2758), which re-implemented the baseline as SuffixReplay* and reports 33% token-identical outputs and 13-17% VT loss at 24-32K on Qwen3.5-9B; this is a different model and implementation from SuffixReplay's own tables, so treat as indicative, not a refutation of the paper's numbers.
