## 2. Key claims

0. **Arch gate: the change applies to every CDNA arch, gfx90a included. It is not CDNA1-only. The steering claim "not gfx90a as written" is OVERTURNED.** The new predicate is `GGML_CUDA_CC_IS_CDNA(cc)`, not `IS_CDNA1`.

1. **The stream-k on/off rule — CONFIRMED.** On GCN and CDNA, stream-k is kept unless `force_tiling` fires. It fires when any one of these holds:
   - (a) the last wave of output tiles is at least 90% full (`100*ntiles/(nsm*nwaves) >= 90`);
   - (b) `ntiles_dst >= 2 * nsm * occupancy`;
   - (c) `k_chunks <= occupancy * tiles_nwaves`, where `k_chunks = ceil(K / K_vram)` and K_vram = 256.

   The stream-k grid is `nsm*occupancy` blocks, capped at the useful work. When tiles < nsm it uses a 512-thread budget per CU instead. **ubatch enters only through the column-tile count (ntj), and type enters only through the config.** The rule never tests ne11 directly.
   - Anchors (diff): `const bool force_tiling = multi_block_cu && (tiles_efficiency_percent >= 90 || ntiles_dst >= 2*stream_k_blocks || k_chunks <= config.occupancy * tiles_nwaves);` and `nblocks_stream_k = std::min(nwork, nsm * std::max(1, 512 / config.nthreads));`
2. **Table retune — CONFIRMED.**
   - Every CDNA entry moves from `(nthreads 512, occupancy 1, I 128)` to `(256, 2, 64)`. This covers Q1_0, Q2_0, Q4_0/1, Q5_0/1, Q8_0, Q2_K…Q6_K, IQ1_S…IQ4_NL, MXFP4 and NVFP4.

   - So "without stream-k" is implemented by the launch-time rule, not by flipping the table flag.
   - Anchors (diff): `- CASE(GGML_TYPE_Q4_K, 512, 1, 128, 16, GGML_CUDA_MMQ_SRAM_LAYOUT_Q8_1, MMQ_ITER_K, true, true);` → `+ CASE(GGML_TYPE_Q4_K, 256, 2, 64, 16, GGML_CUDA_MMQ_SRAM_LAYOUT_Q8_1, MMQ_ITER_K, true, true);`
