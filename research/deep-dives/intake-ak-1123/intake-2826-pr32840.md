## 2. Key claims

1. **"Replace the shfl_xor ladder in warp_reduce_all/any with ballot + lane shift when width is 16 or 32."** — CONFIRMED by the diff (anchor 0). The HIP-only branch is `else if constexpr (width == 16 || width == 32)`, placed after `if constexpr (width == ggml_cuda_get_physical_warp_size())` (which keeps the existing full-wave `__all/__any` path).
2. **Transformation correctness on wave64 gfx90a** — CONFIRMED by reading the helper (anchors 1, 2). `__ballot_sync(~uint64_t(0), x != 0)` returns a 64-bit mask on HIP; `lane` is rebuilt from `v_mbcnt_hi(~0, v_mbcnt_lo(~0, 0))` = 0..63; `votes >> (lane & (warp_size - width))` shifts the lane's own half (width 32: shift 0 or 32) or quarter (width 16: shift 0/16/32/48) down; masking with 0xffff / 0xffffffff and comparing with the full mask gives AND (all), `!= 0` gives OR (any). The `static_assert(width < warp_size && warp_size % width == 0)` rejects a width equal to the wave, which the first `if constexpr` already handles. Result type changes from the ladder's 0/1 int to bool-converted int; same truthiness.
