# DCP-9a private current-snapshot schema v3 (before rerun)

Supersedes v1/v2 private drafts and their unaccepted results. v1 used the wrong denominator; v2's reader materialized skipped string/primitive slices, accepted non-strict numeric conversions and overwrote duplicate allowlisted keys. Those result artifacts are excluded.

Primary source: https://arxiv.org/html/2607.06906v2, §3.1–3.2 (Eq. 4, Eq. 1, Definition 1). Intake-1333#00 records source semantics and arithmetic: `input_tokens` is uncached input; total input is `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`. Eq. 4 `h` uses cache-read divided by the three-component total. Three shares must sum to one for complete nonnegative fields. Do not calculate `p_in_eff` without a pinned price/κ contract. Definition 1 needs ordered completed-task `(Q, τ)` observations under a fixed judge protocol; the source has neither, so status is `not_evaluable`.

Source tree is recursively enumerated at `/home/node/.claude/projects/-workspace/`, JSONL only. Hash each file before parse and after parse; exclude an entire file on mismatch. Persist private manifest containing opaque relative-path SHA256 key, byte size and SHA256 before/after parse. Report and artifact bind both aggregate manifest hashes. Do not expose filenames or path strings. All artifacts will be written exclusively as mode 0600 inside a mode-0700 private custody directory; never overwrite earlier artifacts.

Reader is a standard-library-only custom JSON scanner. Opaque body-bearing strings are byte-index scanned for quote/escape/control syntax without constructing slices, decoding, hashing, or storing the string. Opaque primitive values are grammar-validated by indexed byte reads without token slices. Only short JSON keys and the allowlisted scalar fields are decoded/captured: top-level type/sessionId/uuid/requestId/timestamp; nested message.role; usage input_tokens/output_tokens/cache_read_input_tokens/cache_creation_input_tokens. Duplicate relevant metadata keys fail the row; booleans/floats/null/negative values are not token counts; only exact nonnegative JSON integers qualify. Projection stores allowlisted values plus per-run HMAC IDs/status/time only, no raw IDs or body. Full Unicode validity of opaque body-string bytes is not decoded; report `metadata_parse_failures` and state that limitation, not a broad claim that every source string was semantically validated. Invalid UTF-8/surrogate allowlisted identities remain unknown and are excluded. Timestamps without explicit timezone remain unknown, not assigned UTC.

Raw event sums are duplicate-sensitive and never billing totals. A conservative subset is grouped only by exact `(session HMAC, UUID HMAC)` and `(session HMAC, request HMAC)` identities: repeated UUID rows collapse only if both request ID and usage tuple are identical; UUID group conflicts/missing request IDs are excluded. Every repeated request-ID group is excluded because source semantics do not establish duplicate snapshot vs valid multi-message meaning. Cross-session UUID collisions are not deduplicated and remain unknown. The subset is descriptive only, not billing/task/complete-session authority. Do not publish per-session HMAC rows. If reporting aggregate per-session subset intensity, sum all three input components plus output, and provide only a distribution summary; label partial source-record intensity, never task `τ` or complete-session total.

Historical 61 top-level-file figures remain separate prior cohort, not checksum targets. Emit no filenames, paths, IDs, prompts, messages, body snippets, or individual session HMAC rows.
