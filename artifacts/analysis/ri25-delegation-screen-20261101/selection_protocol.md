# Selection and byte-prefix protocol

1. Read the approved ROOT `RI-25` row at `0c471a946edd8f941551375104641ac4f6f9e026` and the prescribed orchestrator sources at `99791dd` before census.
2. Bound producer locations from host facts: active API CWD and `ORCHESTRATOR_PROGRESS_LOG_DIR`, `ProgressLogger` default, then progress JSONL, non-progress runtime JSON/JSONL, benchmark JSON/JSONL, REPL trace/session stores, and the trace SQLite store. Do not treat the progress directory's latest row as a complete current cohort.
3. During the initial scan, capture each selected source file's exact byte count and SHA-256 as an independent prefix; parse only those bytes. Do not copy the 1.8 GB progress set. Preserve aggregate results, no raw prompts/answers.
4. Keep the original private selection ledgers and their hashes in the operator's scratch. Before making the small publication manifest, re-read exactly each selected byte prefix, verify it matches the original source digest, then record source device/inode and a typed `verified_at_utc`. This publication manifest carries every relative path and exact prefix size/full SHA-256; it omits the old source mtime fields.
5. Replay checks that the path is relative, in-root, regular, non-symlink and the same device/inode; file length is at least the prefix length; bytes hash exactly to the saved SHA-256; inode/device are unchanged across reading. Appends after the prefix are permitted and ignored. Rotation, replacement, short-read, or changed prefix is a hard error.
6. Parse JSON documents as one object and JSONL line-by-line. Recursively inspect every JSON string value, count literal `delegate:` occurrences and generic `delegat` substrings separately, and preserve explicit hits only as hashed locators plus known target or `UNMAPPED:<hash>`. Invalid JSON is counted, never skipped silently.
7. The compact test suite uses temporary JSON/JSONL fixtures for nested future-schema fields, mapped/unmapped role markers, malformed rows, path traversal, appended tails, short source, drift, and rotation. Actual frozen records were also scanned by the CLI; no record contents are bundled.
