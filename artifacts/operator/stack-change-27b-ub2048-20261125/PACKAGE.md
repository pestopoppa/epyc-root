The same report found the deep-occupancy decode stall that motivated -b 512. That stall came from n_batch prompt packing, and this sweep never reached that depth.
Watch KFD for this process for 24 h after bring-up (see section 4). If it goes above 60 GiB, or decode stalls under a deep prefill, roll back.
