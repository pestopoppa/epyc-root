## Compiler recipe (private out-of-tree builds)

The actual read-only Crisp source is `2aa8d7669fcaa18d98d61a4bc8a077464e6b9919` with ggml `e2ae679a563014f46c546ce6c6448e8601e4dea6`, under `/mnt/micron/codex3-cs8-stt2-crisp-20261030/src`; object and shared-library products stay in the original scratch prefix, not this bundle. With `C` set to that Crisp prefix and `D` to the original LID scratch prefix, compile the Whisper C ABI against frozen whisper.cpp `b307379226d93d9c5ed790d7cea0626613c0ef4b`:

```
c++ -std=c++17 -O2 -fPIC -shared -I/mnt/raid0/llm/whisper.cpp/include -I/mnt/raid0/llm/whisper.cpp/ggml/include "$D/lid.cpp" -L/mnt/raid0/llm/whisper.cpp/build/bin -lwhisper -o "$D/liblid.so"
```

For each `k` in `silero_lid firered_asr`, compile the corresponding `"$D/${k}_scored.cpp"` with `c++ -std=c++17 -O2 -fPIC -fopenmp -DGGML_BACKEND_SHARED -DGGML_MAX_NAME=128 -DGGML_SHARED -DGGML_USE_CPU -I"$C/src/src" -I"$C/src/include" -I"$C/src/ggml/include" -c ... -o "$D/${k}_scored.o"`. Link each as `-shared -fopenmp` with `"$C/build/src/libcrispasr-core.a" -L"$C/install/lib" -lggml -lggml-base -lggml-cpu`; the FireRed link also compiles `firered_wrap.cpp`. The concrete executable, library, model, source and code hashes are pinned by the source catalogs. Keep `LD_LIBRARY_PATH="$C/install/lib"` for Crisp and verify each loaded ggml set with the research repo's `verify_ggml_linkage.sh`; Whisper uses its own frozen-tree library path. No production tree was rebuilt or modified.
