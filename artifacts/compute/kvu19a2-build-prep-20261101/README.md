# KVU-19a-2 build preparation (not publishable)

`prepare_sources.py` reconstructs two independent source snapshots via `git archive` from pinned store commit/tree and checks the store-to-candidate patch and both tile hashes. It refuses an existing output and publishes a pair only after both snapshots verify. It does not call a compiler, rowflow, or inference. Use only a new isolated scratch output after owner review; the canonical frozen production tree must never be modified. The snapshots remain mutable and must be hash-bound and protected again at build entry; a manifest alone is not proof of compiler input.

The source pair is a prospective comparison, not evidence that these inputs produced the historical binaries. Git submodules, generated source, required ROCm 6.2 build recipe, worktree resource admission and the host/container mount view have not yet been verified. This script has not reconstructed the full tree on the target host. A safe rowflow build packet still needs an actual source digest at build time, exact HIP compiler/configuration, separate baseline/candidate build dirs, output/disk reservation, deadline and STOP cleanup, ELF manifest, ggml linkage and a short distinct qualification control. Do not publish a row with arbitrary estimates or a launcher that only prepares copies. Full reproducibility and runnable status are not asserted.

Source-pair publication now uses Linux `renameat2(RENAME_NOREPLACE)` with directory file descriptors and refuses symlinked, unowned or group/world-writable scratch parents; the private parent must already exist. This prevents replacing a destination even if it appears immediately before publication. It does not establish durable path identity against an actor with the same UID or authority over an ancestor; the build entry must independently secure custody and bind the actual bytes. The patch is read and validated once and those exact bytes are supplied on standard input to `patch`, avoiding a subsequent path reopen. Five offline tests cover patch-path replacement, empty-directory collision, successful publication, symlink refusal and unsafe parent refusal. No full source extraction or build was run.
