# KPF-18.2 native operation trace — build prerequisite

Private source is git archive a1f0c8cf9bd7102415a72577474f307b8ba94db9, descendant of frozen production ffc1bac82eeca6f9099e1ccd9ba49703c460a115, with only trace.patch. Default-off KPF182_NATIVE_TRACE=1 records native task and slot IDs, selection LCP, chosen checkpoint coordinates and bytes, target and drafter position bounds before and after copy/load, and the actual chosen fork position. The instrument preserves all fork logic and explicitly records unknown component hit/minimum fields: SWA position bounds do not prove contiguous hits and MTP state may reside outside ctx_dft. No component minimum, zero, grade or scientific closure is inferred. Log errors and interruptions must be retained. Future work must define and validate native component semantics before clause-2 comparison.

Full CPU and HIP server builds are separate private output directories, no weights, inference, device execution or production-kernel modifications. The exact same source and launcher control configures the selected backend, compiles the real server-context translation unit and links its object; HIP additionally compiles and links the real acc.cu gfx90a unit. The linked controls are not a full server build. Normal and active compiler STOP with drained children qualify only this build harness; the 27B target and GPU remain untested.
