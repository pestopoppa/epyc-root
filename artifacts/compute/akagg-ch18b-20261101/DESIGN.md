# CH-18.b short-context SWA cache coverage: design hypothesis

C5 `c72ec82f5417bb2937310326120f149b665e8400`, upstream `785322d17f2d51e5185cf996a1f4e46d87640841`. This is source reasoning, not a tested patch or runtime claim.

C5 `server-context.cpp` computes `max(0,pos_next-n_swa-(has_new_tokens?0:1))` and searches checkpoints when `pos_min>=threshold`. Upstream #30580 `61ad80bf93de0ac03a29f83f5f3e9f596bf40c2d` fixes the two-cell boundary but preserves the `max(0,...)` zero-threshold behavior. `threshold-cases.json` lists the arithmetic.

For STANDARD causal SWA, `llama_hparams::is_masked_swa` masks p0 when p_eval-p0>=n_swa. Thus an attention cache for the first evaluation needs existing prior positions `[max(0,p_eval-n_swa+1), p_eval-1]`, where `p_eval=pos_next-(has_new_tokens?0:1)`. A real no-restore predicate must prove the correct matched prompt's complete contiguous required interval and any full-attention history, as well as safe truncation of divergent suffixes. Minimum and maximum alone do not prove absence of holes. Empty prior interval must be handled explicitly. Position mappings for multi-modal tokens may be non-unit; do not infer contiguity from token counts.

Critically, `llama_memory_hybrid_iswa::seq_pos_min` returns max(attention-min,recurrent-min), while recurrent `seq_rm` can fail or require bounded snapshots; the server's `common_context_seq_rm` aborts on failure. Identical fully cached prompts deliberately re-evaluate one token for logits; speculative draft state must be kept consistent. Do not treat `pos_min==0` as sufficient proof and do not change the existing predicate for recurrent/hybrid memory, ambiguous draft state, noncausal models, shifted/gapped positions, multimodal input, nonstandard SWA, unknown occupancy, or unsupported removal. CHUNKED and SYMMETRIC SWA have different masks. A narrow experimental path needs an explicit native cache coverage/capability proof, not merely a model-name heuristic; fallback to existing behavior if any evidence is missing. Upstream #30666 independently protects against retaining checkpoints with unshared prompt tokens and needs its own regression coverage.

Predeclare tests: pure standard SWA text model, n_swa 64 and prompt/evaluation lengths below, at and above 64, including exact common-prefix continuation, divergent suffix, fully identical prompt, slot-save/restore, RAM-cache restore, and no checkpoint. Compare post-change warm vs cold greedy tokens and logits (declared tolerance), report `cache_n`/`prompt_n`, assert no unnecessary restore only where coverage proof is present. Negative controls inject an interior hole with unchanged min/max, missing seq (-1), start after required earliest position, invalid/shared-prefix mismatch, failed/too-deep seq_rm, stale checkpoint, target/draft mismatch, and chunked/symmetric/noncausal/MTMD/hybrid/recurrent cases: all must fall back, never silently reuse. Test multi-slot isolation, prefill ubatch splits, RS snapshots, and required one-token replay. Where inability to prove a condition is the point, verify fallback plus same correctness as the original. Apply upstream #30580 tests for the two-cell edge and #30666's divergent-prefix test separately; neither test subsumes CH-18.b.
