Held-out scoring draft: score_heldout.py refuses to open test references until the actual dev selection, held-out plan and all 25,095 predeclared native results (22,830 original scope cells plus 2,265 auxiliary auto-language Whisper calls) exist and their hashes, runtime/model/recipe bindings and original exposure grants validate; successful boosted calls also require positive active-trie traces and a matching live sample. It computes the M16 numeric predicate exactly from the three original guards; unresolved AA membership and CS-4 coverage are reported separately and do not invent an additional numerical guard. Ordinary lexical WER and term-masked WER remain explicitly distinct from P-STT-1 v1. For Whisper, report each clip’s maximum consecutive identical normalized-token run and count a descriptive repeated-token loop at 10 or more; this is a predeclared reporting definition, not an acceptance threshold. Contextual test clips additionally get no-prompt, global and local auto-language Whisper requests to observe language flips without changing the frozen-English comparator; FLEURS Whisper already uses auto language. Language detection/flip remains UNKNOWN where the native log does not support it. This scorer is a draft, not a qualified executable or test result.

Failure policy: preserve every original native attempt. A completed native failure on Contextual Earnings contributes the task-prescribed blank hypothesis/full deletions; its failed status stays visible. A completed selected-arm FLEURS failure cannot prove absence of an insertion, so that language and pooled insertion rate remain UNKNOWN instead of treating the blank output as zero insertions. An exposed attempt without a native result remains UNKNOWN and blocks a complete held-out score. No threshold or extra approval is added.

FLEURS insertion rates are reported separately for all six original conditions and each language. The no-context Nemo and no-prompt Whisper baseline hypotheses are scored against the same dev-selected probe-list scope as the selected arm; an empty request does not make the insertion denominator vacuous. Auto-language Whisper calls are descriptive auxiliaries and never replace the original comparator or alter the M16 predicate.

Before any held-out exposure, make_instance_plan.py freezes the actual selected alpha/scope, all six original cells and three Contextual auto-language auxiliary cells, the 25,095-attempt denominator and the exact source/context/policy hashes. This creates a deterministic instance from the actual dev selection; it is not a new approval gate.
