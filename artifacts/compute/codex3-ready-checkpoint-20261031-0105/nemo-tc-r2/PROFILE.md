# Nemotron validation execution profile

The supported pinned checkpoint contexts R0/R3/R6/R13 each run in native automatic-prompt and forced-locale mode; R1 remains an explicit unavailable trained-setting row. Native chunk sizes are 80/320/560/1120 ms respectively. Each of the 1,437 FLEURS validation inputs is assigned by immutable manifest index modulo worker count to one worker; every worker executes all eight settings for its own inputs. On a granted 24-CPU quarter the same dispatcher launches eight independent workers on disjoint groups of three CPUs, under one 32 GiB correctness reservation. Worker outputs, exposure identities and the 620-second no-new-case reserve are preserved independently; the parent combines only completed worker summaries. STOP or any worker interruption drains the other workers and yields rc 75. Two-CPU R11 diagnostics invoke the identical dispatcher with two one-CPU workers, each running R3 auto and forced on a diagnostic copy of JFK; a separate native diagnostic already exercised all eight combinations under the 8 GiB limit. This is an execution profile, not a setting-selection or test-scoring criterion.

The traced CLI emits an explicit successful native completion and unfiltered raw token count, including zero. A completed empty native transcript is a deletion even if its token evidence is missing; that missing UNK count remains unknown.
