## Predeclared GPU measurement

Use exclusive GPU resources and distinct new run paths. Each treatment comprises full baseline and candidate binaries, mask skip disabled (`GGML_CUDA_FA_MASK_SKIP=0`), identical materialized inputs, and five separately launched repetitions of each retained case 78, 79 and 80 per binary. Counterbalance treatment order ABBAABBAAB per case so each has five repetitions; record order and every launch. Require same source-bound executable and mapped library digest within each arm, target gfx90a identity, live nonzero VRAM/KFD process evidence during each run, input equality across all repetitions/arms, normal exit, complete output byte counts, and verified owned-process cleanup. Pin and report the exact sampling interval before publication. The repetition count bounds this experiment; absence of a difference in five runs is not proof of determinism or upstream correctness. If a case is unsupported, inputs differ, residency/linkage/custody cannot be demonstrated, or any run is partial, report INCOMPLETE for that case and do not silently drop a run.

For each complete case and binary compare full raw output bytes within that exact binary: any differing pair is OBSERVED-NONDETERMINISM for that binary and case; five byte-identical outputs are NO-DIFFERENCE-OBSERVED (n=5), not a pass proving determinism. Record cross-binary differences and NMSE separately; those alone do not establish nondeterminism. Detect nonfinite values separately rather than equating them with a changed hash. A candidate-only result does not show an unmodified upstream defect, and no mechanism is established without further evidence. Preserve native run output, source/build attestations and immutable original evidence.

Qualification only uses a distinct, short, clearly labelled control with its own native per-item output and exercises the actual keeper path; it must not count as a repetition. The owner files the actual result and receipt after the keeper runs it. Set result path, bounded duration, resource claims, exact baseline/candidate builds, output storage reservation and writer identity only after verified preparation; no arbitrary placeholder is a publishable estimate.
