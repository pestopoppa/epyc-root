# KVU-19a-2 build command planner — offline, not publishable

`plan.py` is a pure command planner, not a launcher. It checks the pinned source commit/tree/patch IDs and requires prospective tool and source-manifest SHA-256 values. The target plan emits separate baseline/candidate gfx90a HIP CMake commands and distinct output roots; qualification emits a separate trivial CMake control and output path. Four synthetic tests exercise separation, malformed identity, path restrictions, target-only manifest requirements and explicit mode. No build or compute was run.

The caller must create and hash an actual tiny control source before a keeper qualification; this draft does not create it. The declared hashes are syntactically validated only, not verified against files. CMake flags are a prospective partial recipe, not proven equivalent to the house recipe or sufficient for either target. HIP toolchain transitive dependencies, full source/submodule and generated-file sealing, durable output and event writer, engine wrapper/mode propagation, actual in-claim resource reservations and estimates, STOP/descendant cleanup, ELF and ggml linkage manifest, and independent review remain mandatory. The qualifying events must be written by the real control after successful build and cleanup. No row is ready and this artifact must not be treated as an executable producer.
