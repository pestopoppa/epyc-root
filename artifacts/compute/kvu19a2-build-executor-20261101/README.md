# KVU build execution coordinator — offline component

`executor.py` executes a predeclared command sequence through an injected supervisor and journal. It refuses unknown or changed mode, malformed commands, STOP, unverified input custody, nonzero exit, unverified child cleanup and unverified outputs; no subsequent command or completion is recorded after a failure. The initially validated mode is passed to every verifier, and detected plan-mode changes stop execution. A command digest is journaled before each call. Seven synthetic tests cover the original failure cases and plan-mode mutation during a command or verifier. No real process, compiler, inference or build was launched.

This is an execution component, not a rowflow launcher or deployable producer. It does not itself provide a real process supervisor, kernel-enforced child/descendant cleanup, actual source/toolchain sealing, plan-to-recipe attestation, durable output verification, deadline handling or a native evidence writer. Its injected supervisor must own cleanup even on spawn failure, and its verifier callbacks must inspect actual immutable inputs and outputs. Journal start/write failures and supervisor exceptions leave partial evidence, never a successful completion. No claim follows from fake tests; do not publish or schedule this component without those missing pieces and independent review.
