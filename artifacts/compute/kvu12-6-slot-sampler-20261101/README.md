# KVU-12.6 native slot sampler component

`slot_sampler.capture_slot_sample` is a callable producer component that retains each complete native loopback `/slots` HTTP response as raw UTF-8 with monotonic start/end and wall-start timestamps, or an explicit error. It launches no server and performs no request until called by a future owner. The response size is bounded and the socket operation has a timeout; this is not a total deadline, and a slow trickle can extend the observation. Redirects are refused and environment proxies are disabled by the default opener; an injected opener is a trusted test/adapter contract and must preserve those properties. The actual peer is not verified; source is unbound until the eventual packet seals it.

The current component does not prove which process served the port, poll on its own, identify a decoding window, prove unique unified KV cells, retain request or resume-depth evidence, enforce interval/occupancy matching, write a durable journal, qualify a row, or own cleanup. In particular, summing per-slot token counts can double-count shared cells and must not be labelled measured unified occupancy. A complete producer must use process/binary-bound native evidence, establish synchronized request/decode windows, predeclare and capture sampling gaps and matching policy, and preserve the original responses plus request/response witnesses. Missing observations are INCOMPLETE. No row is publishable from this component.

Seven isolated fake-HTTP tests cover redirect refusal without a follow-up, default opener configuration, raw byte preservation, response windows, malformed/oversized responses, loopback restriction and failed calls. No server, model or inference was run.
