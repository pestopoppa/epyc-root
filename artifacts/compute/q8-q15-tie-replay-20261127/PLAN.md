# Q8/Q15 final-head replay

Question: Does per-32 signed Q15 activation packing restore FP32-reference greedy decisions on the frozen rows without a new held-out mismatch or lost full-head throughput?

- Model: installed Qwen3-0.6B Q8_0. Freeze the original GGUF output weight bytes, one float32 pre-head activation row per decision, tokenized prompts and incumbent-continuation prefixes, native logits and the FP32 reference logits computed from the same Q8 weight bytes. Source and shared libraries: V10 frozen CPU store, checked against its manifest. Candidate: standalone AVX-512 VNNI replay, with signed byte weights widened to signed words. No served checkpoint or kernel changes.
- Matrix: four calibration prompts and eight independently specified held-out prompts. Record six next-token decisions per prompt along the same incumbent greedy path. Use calibration positions only to construct deterministic real-weight near/wide top-two controls at signed gaps 0.00025, 0.001, 0.01 and 0.25 in both directions. Retain original natural margins as well. Replay identical activation bytes and head weights at 1, 8 and 24 threads.
- Isolate each packed head using the same weight layout, resident input, loop and row partitioning. Also replay/timestamp the deployed native head and check against captured full-graph decisions. Keep native greedy selection fixed across all FP32/Q8/Q15 logits, recording IDs before and after it. The November 26 boundary-tie replay separately changes filters/draws against identical manufactured logits.
- Per-block signed Q15 uses float32 max-abs/32767 scale and nearest-even rounding. Compare every saved top-two block accumulator and deterministic mixed-sign/extreme inputs with a scalar int64 sum. Include the overflow of two products of signed -32768 words and the non-saturating versus saturating behavior. Use FP32 FMA on dequantized signed Q8 weights as the unquantized-activation reference, and compare the selected logits against independent FP64 sums.
- Full-head timing includes packing and all vocab rows. Also collect Q15 prepacked timing and independently time both packers. On the same grant, interleave native Q8, matched Q8, matched Q8 repeat, Q15 and prepacked Q15 over eight same-input rounds at each thread count. Higher head evaluations/s is better. Report median paired candidate/incumbent throughput ratios and an empirical A/A repeat floor from median absolute paired deviations. An observed gain must exceed the same-count floor and hold after packing. Head timing is a kernel-local throughput diagnostic.
- Stop after the entire matrix and timing frame are valid. Refuse promotion if any held-out Q15 winner differs from the FP32 reference on a row the incumbent gets right, if the candidate loses the measured Q8 throughput after conversion, or if the test cannot demonstrate a gain above noise. This diagnostic makes no production claim. Stop as invalid on unverifiable input bytes, failed scalar oracle, inconsistent greedy sampling, or insufficient valid timing coverage.
