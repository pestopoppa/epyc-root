# G1b host isolation — review-only, no worker launch

`probe-only.sh` invokes host chroot/setpriv, then `env -i` and `/usr/bin/python3 -I -B`; the target worker and models are never called. Invoke it with `/bin/bash -p`; this is necessary because ordinary noninteractive bash can process `BASH_ENV` before the script gets control. The current keeper's ordinary `bash` invocation does not satisfy that property; the owner needs an integrated, reviewed launch path rather than an assumption that the script's shebang is honored. No keeper was modified.

`preflight.py` checks an exact hash of `RUNTIME-LOCK.REVIEW.json`; rejects inherited Python, loader or GGML overrides, nonisolated Python, a missing/symlink/nonempty working directory, changed/missing pinned files, or any backend-directory membership, symlink target or content change. The catalog binds 2,028 paths and exact 27 ggml/Whisper library aliases under the two executable directories. Actual host probe passed with deliberately hostile PYTHONPATH, PYTHONHOME, LD_LIBRARY_PATH and GGML_BACKEND_PATH in the parent environment; unit tests also check injected BASH_ENV under `bash -p`, library/cwd drift and changed files. The probe changes to its verified empty cwd after checking it. These checks are a review instrument, not a live admission or isolation boundary.

`verified_bootstrap.py` demonstrates, with synthetic fixtures only, that explicitly adding a hash-checked local module directory allows a `-I` Python process to import a pinned helper, while altered and symlinked modules are refused. It is not invoked by the probe or wired to the real worker. A real integration must pin the worker, selection gate, audit module and their complete import closure, enforce a safe no-mutation boundary between hash checks and imports, and preserve the exact owner-provided admission/stop environment without overriding keeper state.

`launch-worker.REVIEW.sh` unconditionally refuses rc78 before the host transition. It is a sketch, not a working launcher. Removing the refusal changes its hash and requires a new review/pin. Original/successor writer exclusion, real selection/input freeze, canonical engine integration, normal and active-stop keeper qualification and source-catalog pinning remain outstanding. Do not run target inference or publish this package.

The inventory comprises files observed in a model-free host import/synthetic-resample probe plus native ldd candidate resolution; it cannot establish all lazy branches or the libraries selected during actual model execution. ggml source can scan the executable directory, current directory and a compiled backend directory. The probe constrains the first two, but a build cache is not content-based proof of the compiled third directory; it remains UNKNOWN until the final binary is inspected or actual execution witnesses a controlled resolved closure. CPU-only environment and pinned library bytes are not by themselves proof of the runtime backend.
