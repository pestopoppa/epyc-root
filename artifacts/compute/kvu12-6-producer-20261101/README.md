# KVU-12.6 source-bound matrix preflight

`matrix_preflight.py` checks the exact retained driver SHA-256, applies the two-length substitution in memory, parses the result and evaluates only its `LS`, `fits` and `build_launches` definitions. It refuses source drift, an ambiguous/missing definition, or a requested cell absent from the driver's actual matrix. It emits a prospective six-cell unified pool 524288 matrix: np8/32k vs np4/64k, np8/48k vs np4/96k, np8/64k vs np4/128k. The middle pair addresses KVU-12.6; the outer pairs are proposed controls, not an authorized final inference protocol. It prints base/patched hashes, not a source file or server command. It never invokes the original module entrypoint or launches compute.

The real driver selection is checked because its `build_launches` silently drops unknown lengths. The hash-bound preflight yields patched source SHA-256 `5c4e6b152db55294d290c333580c358351600ec82ea1cf1c1011a8c976fd0c2f`. Tests refuse altered sources, an unknown length and overflow; `python3 -B artifacts/compute/kvu12-6-producer-20261101/test_preflight.py` passed five offline tests on the retained source.

**Not runnable or publishable**: this is a concrete matrix preflight, not a measurement producer, launcher, or evidence capture. The original driver only records per-wave prompt/cache counts and timing; it does not independently sample live resident KV cells. Nominal `np × L` equality is not proof of observed occupancy equality, particularly with per-stream reserves and different resume depths. A safe successor still needs a producer recording timestamped native resident cells during the relevant decode window and exact per-stream prompt/cache/resume depths, a prospectively declared matching criterion, immutable source/corpus/model/binary binding, resource estimate, separate keeper control, GPU-quiet proof, STOP/owned cleanup and belief write-side capture. No inference, qualification, or compute ran.
