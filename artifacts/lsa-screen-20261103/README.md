# LSA screen inputs

64 distinct synthetic document identities, 32 per split; each contains 8 tasks per group. Multi-hop facts occupy separate prompt thirds; exact retrieval sentinel placement varies by item. Filler is synthetic and repetitive, so this diagnostic cohort does not establish natural-document performance. 262144 cells reserve 256 output tokens. Inputs are token IDs, not reconstructed strings.

`prepare.py` creates identities. `freeze.py` checks tokenizer examples against GGUF, hashes the GGUF/tokenizer and freezes ID arrays; run with the scratch venv and region lock. Four probes do not prove complete vocabulary equivalence; IDs are directly passed to the runtime, which must verify served `prompt_n` and token identity. Maps, runtime source, topology and effective configuration remain pending until reviewed binding. No held-out documents may be used for PCA fitting.

`runner.py` accepts a reviewed binding and writes one immutable JSON record for each declared item/arm/phase/repetition, including unsupported, capacity, failure, timeout and abstention outcomes in the denominator. Binding specifies `model_sha256`, `source_commit`, `effective_config`, `reviewed`, `supported_arms`, `map_sha256`, `adapter_argv`, and `timeout_s`. Adapter stdin is a JSON object with token_ids, max_tokens, arm, phase, seed and effective_config; stdout is a single JSON object containing output and any available TTFT/TPOT, memory, selector time, budget and recall fields. The runtime has not yet committed to this adapter; unsupported controls must remain unbound. Record capacity faults as invalid by supplying an unsupported arm binding with the capacity reason in effective_config.

Quality is one held-out evaluation; timing happens in a later reserved window, initially three paired repetitions, at most seven if unresolved. Stop affected arm on parity defect and cell on capacity fault. Report every group/device/length separately. Quality guard: no new exact-sentinel failures and at most one additional failure per 32 versus dense; seek 10% TTFT reduction with TPOT regression at most 5%. Missing metrics or unresolved spread are inconclusive. Oracle top-k and attention mass/top-key recall are sampled-query diagnostics where full-context oracle is infeasible; their exact sample and budget must be bound and recorded. Concurrency 1 first; concurrency 4 only with capacity. Speculation off and equal precision for initial comparison.

The staged controller and stop contract are `controller.py` and `DECLARATION.md`; a reviewed binding must include candidate build root, owned server PID and process birth ticks. The monitor refuses a serving process with mismatched executable, stale PID, foreign mapped ggml, missing ldd, or missing in-window GPU residency. Each raw record is followed synchronously by the existing research-screen writer through `native_evidence.py`; a write failure pauses the controller. Source registration and planning-context canary are separate prerequisites owned by the parent.

### Versioned no-think derivation

`freeze.py`, `manifest.json`, and their input IDs are historical frozen artifacts; do not rerun or edit the freezer. For new Qwen3.8 no-think screens, use `derive_no_think_inputs.py --manifest manifest.json --tokenizer <matching-tokenizer.json> --proof c5-tokenizer-parity.json --smoke-manifest cpu-sparse-no-think/manifest.json --output-dir <new-separate-directory>` under a CPU region lock. It verifies the frozen hashes, four-probe C5 parity and the independently recorded no-think wrapper, then preserves the question and evidence while exchanging 12 verified leading filler tokens for the 12-token wrapper. The generated manifest binds its source, tokenizer, proofs, renderer and row hashes; token counts and output reserve remain unchanged. The C5 proof covers four sample texts, not the entire vocabulary. Point `runner_v2.py --manifest` at that new manifest; IDs resolve relative to it. Keep fitting and heldout source IDs disjoint, and do not tune or inspect heldout model outputs while choosing settings.
